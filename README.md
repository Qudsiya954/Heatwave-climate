**Climate Intelligence** is an AI-powered heatwave forecasting and early-warning platform for India that processes historical IMD temperature data from 2010–2025 together with IoT/AWS weather observations. The system performs data cleaning, validation, spatial and seasonal analysis, feature engineering with lag, rolling, anomaly, and regional-threshold features, then uses LightGBM to forecast next-day maximum temperature and XGBoost to predict heatwave probability. Forecasted temperatures are converted into Normal, Moderate, High, or Extreme severity using regional P95, P97.5, and P99 thresholds. The platform also detects historical heatwave hotspots using heatwave frequency, extreme-temperature frequency, severity, and anomaly, then combines these results with forecast intensity, probability, persistence, and hotspot information to calculate the Dynamic Heatwave Risk Index (DHRI). AWS observations are compared with forecasts using MAE, RMSE, and bias for validation. A decision-support layer generates No Warning, Watch, or Issue Warning decisions, while Gemini produces stakeholder-specific advisories for citizens, farmers, health agencies, and local authorities. Results are stored in PostgreSQL, exposed through FastAPI endpoints, and visualized in a React/Leaflet dashboard showing forecasts, probabilities, severity, hotspots, DHRI, decisions, AWS validation, and advisories. The planned free deployment uses Vercel for the React frontend, Render’s free web service for FastAPI, Neon’s free PostgreSQL database, and GitHub Actions for scheduled batch pipeline execution.
